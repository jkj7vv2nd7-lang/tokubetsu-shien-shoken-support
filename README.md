# 特別支援学級 所見作成支援システム Web版

**Version 9.0.0**

特別支援学級の先生の「見取り」を中心に、既存の記録を  
**見取る → 残す → 確認する → つなぐ → また見る**  
という仕事の流れにつなげる単一HTML型Webアプリです。

## 基本方針

- 入力画面を増やさず、既存の記録を複数の仕事へつなげる
- 一人の子どもを中心に、所見・履歴・成長シート・面談準備・次の支援・年度レビューをつなげる
- 日々の記録から「今見るべきこと」「次につなぐ仕事」を整理する
- システムが子どもの評価や支援方針を自動決定しない
- 最終確認・判断は先生が行う

## v9.0.0の主な進化

### 見取りOS

先生の仕事を、

1. 見取る
2. 残す
3. 確認する
4. つなぐ
5. また見る

という循環として整理しました。

既存の記録を利用して、現在の状況、最近の変化、確認が必要な観点、次の仕事を見通せるようにしています。

### 今日の先生の仕事

今日の見取りに必要な情報をまとめ、

- まず見る
- 変化を確かめる
- 次へつなぐ
- 今日の見取りフォーカス
- 最近の変化
- この子の現在地
- 次の仕事

を一つの流れで確認できます。

### 観点別・見取りナビ

子どもごとの記録を観点別に整理し、

**この子 → この観点 → 記録 → 変化 → 次の支援**

という流れで確認できます。

### 支援サイクル

支援を、

**見取る → 残す → 比べる → つなぐ → また見る**

という継続的なサイクルとして確認できます。

### 年間サイクル

年間の記録を、

- 4～7月
- 8～12月
- 1～3月

の流れで確認し、次年度へ残す情報も整理できます。

### 先生の仕事レビュー

既存の記録・履歴から、

- 記録状況
- 最近の記録
- 複数回記録された観点
- 変化を確認できる観点
- 年間の記録
- 次に確認したい事項

を整理します。

これは先生の判断を補助するための機能であり、評価や支援方針を自動決定するものではありません。

## GitHubへの公開

GitHubリポジトリに本パッケージを配置し、`main`ブランチを公開版として使用します。

GitHub Actionsでは、バージョン、HTMLの整合性、重複ID、JavaScript構文などを自動点検します。

## Vercelへの公開

GitHubの`main`ブランチとVercelを接続することで、`index.html`を入口とした静的Webアプリとして公開できます。

## Vectorへの配布

`app.html`は単一HTMLとして配布できます。

Vector掲載時は`VECTOR_MANUAL.md`を説明資料として利用できます。

## データについて

基本的な記録データはブラウザ内で管理されます。

必要に応じてJSONバックアップを作成し、別の環境へ復元できます。

学校で実際に利用する場合は、端末・ブラウザ・校内ネットワーク等の運用ルールも確認してください。

## Gemini APIについて

Gemini APIを利用する場合、現在のWeb版はブラウザからAPIへ直接接続する方式です。

ブラウザ側にAPIキーを置く方式は、公開サービスとして秘密情報を完全には保護できません。

公開運用でAPIキーを安全に管理する場合は、サーバー側プロキシ等への移行を推奨します。

個人情報・要配慮情報を入力する際は、学校の情報管理規程、利用するAIサービスの規約、所属自治体・学校の方針を確認してください。

## 先生が最終判断します

このシステムは、先生の仕事を置き換えるものではありません。

記録の解釈、子どもの評価、所見の内容、支援方針、保護者への説明などについては、必ず先生自身が確認・判断してください。
