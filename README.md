# 特別支援学級 所見作成支援システム Web版 v9.2.1

先生の見取りを起点に、記録・所見・面談・次の支援をつなぐ単一HTMLのWebアプリです。

## v9.2.1
- 「先生の仕事を1本につなぐ」導線を追加
- 見取る → 確かめる → 残す → つなぐ、の4段階を既存機能へ接続
- 入力画面や保存データ構造は増やさず、既存情報を再利用
- 10分で使ってみるガイド、ヘルプ、3分ガイドを継続
- 先生が最終判断する設計を維持

## ファイル
- `index.html` / `app.html`: 同一内容のアプリ本体
- `QA_REPORT_v9.2.1.md`: 公開候補QA
- `SHA256SUMS.txt`: SHA-256チェックサム
- `.github/workflows/validate.yml`: 静的検証

## 注意
文章化支援で外部AI APIを利用する場合、入力内容が外部サービスへ送信されます。学校の情報管理規程に従い、機密情報の入力には十分注意してください。
